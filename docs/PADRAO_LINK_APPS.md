# LinkSul Tools for Linux

Cada aplicativo da coleção tem pacote .deb, comando, atalho e dependências próprios. Use `link` seguido do nome do aplicativo, em minúsculas e sem separador, no comando e no pacote. No menu, use LinkPrint, LinkScan, LinkNetTest, LinkChat e LinkClima.

O identificador deste aplicativo na coleção é `linkprint`. Valide instalação, migração dos dados e fluxos de uso antes de retirar a distribuição anterior.
